# Tienda 404

Proyecto de una tienda online de perfumes que simula el funcionamiento de un e-commerce, con un frontend desarrollado con tecnologías web básicas y un backend encargado de gestionar los productos mediante una API REST conectada a una base de datos MySQL.

## Tecnologías utilizadas

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Base de datos

* MySQL

## Funcionalidades actuales

* Visualización de productos.
* Consulta de perfumes desde una API REST.
* Gestión de productos almacenados en base de datos.
* Separación entre frontend, backend y base de datos.
* Despliegue del backend en la nube.
